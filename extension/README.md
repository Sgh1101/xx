# X 영상 다운로더 (크롬 확장)

X(트위터)에 들어가면
- 영상이 있는 트윗마다 액션바에 **다운로드 버튼**이 생기고,
- 계정 페이지(`x.com/계정`)에서는 우하단에 **"끝까지 스크롤하며 수집" / "전체 다운로드"** 패널이 떠서 그 계정의 영상을 한 번에 받습니다.

파일은 `다운로드/X-Videos/계정_트윗ID.mp4` 로 저장됩니다.

## 설치 (PC 크롬/엣지/브레이브)
1. `chrome://extensions` 접속 → 우상단 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택
3. x.com 새로고침

## 동작 원리
로그인된 브라우저에서 X가 불러오는 API 응답을 읽어 영상 mp4 주소를 얻습니다. 별도 서버·로그인·API키가 필요 없어요.
X 내부 구조가 바뀌면 `hook.js`의 파싱 부분을 고쳐야 할 수 있습니다.

본인이 볼 권리가 있는 콘텐츠를 개인 용도로만 사용하세요.
